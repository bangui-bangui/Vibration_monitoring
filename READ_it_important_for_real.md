This project is a real-time vibration monitoring system for industrial equipment in a Sebico process installation.
The touchscreen displays a schematic of the installation, including components such as the ventilator, crusher (broyeur), sieve (tamis), elevator (élévateur) and dosing screw (vis dosage).
Each component has an associated vibration indicator. When the user clicks on a waveform icon, the interface displays the vibration data associated with that equipment, allowing the user to examine its vibration behavior.
The objective is to monitor machine condition, detect abnormal vibrations and help identify potential mechanical faults, such as imbalance, misalignment or bearing wear.
The ESP32 manages the touchscreen interface, while LVGL handles the graphical elements and user interactions.
